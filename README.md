# StoryVault Africa

StoryVault Africa is an AI-powered research and narrative generation agent designed to preserve, scrape, and surface rich African historical and cultural intelligence.

## Features
- **Cultural Intelligence Extraction**: Scrapes and synthesizes historical narrative contexts.
- **Pay-Per-Event Integration**: Optimized for seamless Apify Store execution.

## Input Example
Provide a prompt describing the historical event or cultural theme:
```json
{
  "prompt": "A narrative on the Oyo Empire during the 18th century."
}
